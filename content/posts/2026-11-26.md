#### Wavefront: Low-Rank Drafting with Parallel Causal Refinement for Speculative Decoding

**来源：** arXiv（cs.AI），arXiv:2611.31638 ｜ **时间：** 公告 2026-11-25，提交 2026-11-23 22:28 UTC / 2026-11-24 06:28 CST ✅ verified live

把推测解码的满 lm_head 换成可学习低秩基底、校正头以并行 Jacobi 迭代求解，整段草稿步可捕获为单个 CUDA graph 落在 vLLM 中；Qwen3-8B 上吞吐比对照方法平均高 2.6%–23.6%，长上下文 SPEED-Bench 上高 9.6%–28.9%。

[原文链接 →](https://arxiv.org/abs/2611.31638)

#### RankServe: Rank-Aware CPU-GPU Scheduling for Memory-Constrained MoE Serving

**来源：** arXiv（cs.DC），arXiv:2611.31869 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 03:21 UTC / 11:21 CST ✅ verified live

针对低秩压缩 MoE 检查点做 CPU-GPU 服务调度：按每专家秩与 token 负载折算“单位字节节省”决定 GPU 常驻优先级，变秩执行无需统一 padding；在 vLLM 上三个 MoE 模型相对各配置最快基线，TTFT 快 1.69–2.29 倍、TPOT 快 1.71–2.48 倍。

[原文链接 →](https://arxiv.org/abs/2611.31869)

#### LoomKV: Lossless KV Cache Compression from GPU Memory to SSD for LLM Serving

**来源：** arXiv（cs.AI），arXiv:2611.32954 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 16:54 UTC / 2026-11-25 00:54 CST ✅ verified live

无损 KV 压缩同时覆盖外部层（LMCache 层）与 GPU 显存池：BF16 KV 压到 0.71 倍、FP8 压到 0.85–0.87 倍；层模式下 goodput 达原始的 2.7–3.6 倍、TTFT 降 1.9–3.1 倍，池模式多装 1.31–1.34 倍 token，容量充足时吞吐代价至多 2.2%。

[原文链接 →](https://arxiv.org/abs/2611.32954)

#### MXFP4 for LLM Inference: Complementary Post-Training Quantization Techniques and Their Interactions

**来源：** arXiv（cs.LG/cs.AI），arXiv:2611.32873 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 16:06 UTC / 2026-11-25 00:06 CST ✅ verified live

在 6 个 LLM 与 MXFP6/MXFP4/NVFP4 三种微缩放格式上系统比较旋转、PTQ 算法与 scale 选择的组合：有效配方是格式相关的，MXFP4 更受益于旋转与纠错 PTQ；提出免标定的 Midmax scale 选择策略，MXFP6 激活 + MXFP4 权重在 Llama-3.1-8B 上达到甚至超过 BF16 基线。

[原文链接 →](https://arxiv.org/abs/2611.32873)

#### LLM Agent Authorization Across Context Compaction

**来源：** arXiv（cs.CR/cs.AI），arXiv:2611.32194 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 08:44 UTC / 16:44 CST ✅ verified live

上下文压缩会破坏请求派生授权（Progent）的归属假设：Claude Code 与 Codex 都把模型写的摘要当作 user 消息，攻击者注明的收款账户在压缩后策略里通过率达 91%（用用户原话则为 0）；修复是只信任到达时已认证、原文传递的用户文本，40 组 AgentDojo 受攻击复现中攻击者无一得手。

#### ShellBench: What Matters More for AI Agents, Models, or Harness for Everyday Tasks

**来源：** arXiv（cs.AI/cs.CL/cs.SE），arXiv:2611.32946 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 16:48 UTC / 2026-11-25 00:48 CST ✅ verified live

100 个基于 1000 万以上真实用户请求的日常任务，12 个模型 × 5 个 harness × 3 档推理共 53,100 次 rollout：模型选择比 harness 更重要，但前三模型仅差 1.1 个百分点；GPT-6.1 Sol 通过率 61.4%，单次成本约为 GPT-6 Astra（62.5%）的六分之一。

[原文链接 →](https://arxiv.org/abs/2611.32946)

#### Leto: Utility-Centric Agent Memory

**来源：** arXiv（cs.CL），arXiv:2611.33005 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 17:30 UTC / 2026-11-25 01:30 CST ✅ verified live

把 agent 记忆从“忠实记录过去”改成“预测未来效用”：记忆索引保留对话细节来源，按请求预判并供给所需上下文，再用响应结果闭环优化记忆选择；PrefEval 上比最强对照记忆系统高 16.3 个百分点，MemoryArena 长程任务整体最优。

[原文链接 →](https://arxiv.org/abs/2611.33005)

#### fork() for Agents: Agent Kernel for Non-blocking LLM Orchestration

**来源：** arXiv（cs.CL/cs.DC），arXiv:2611.31727 ｜ **时间：** 公告 2026-11-25，提交 2026-11-24 00:33 UTC / 08:33 CST ✅ verified live

把分布式系统的子图选择性恢复搬到 agent 运行时：失败节点只重执行其传递后代、保留已完成兄弟节点并继承上下文；14,434 次运行中预算为 3 时完全恢复率 100%（全轨迹重放 55%），比 Sherlock 回滚快约 10 倍，结构允许时并行加速最高 12.7 倍。

[原文链接 →](https://arxiv.org/abs/2611.31727)
